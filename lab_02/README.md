# Лабораторна робота №2: Очищення, фільтрація та аналіз даних за допомогою Pandas

## Опис роботи
Ця лабораторна робота присвячена практичному аналізу великих масивів даних за допомогою бібліотеки `pandas`, а також часовому профілюванню операцій за допомогою модуля `timeit`. Робота складається з двох окремих модулів аналізу:

1. **Частина 1: Аналіз VHI індексів NOAA**
   * Автоматичне завантаження та парсинг текстових файлів з серверів NOAA.
   * Очищення даних від службових символів та приведення до відповідних типів.
   * Реалізація 3-х специфічних аналітичних процедур (пошук екстремумів VHI, виявлення років глобальних та помірних посух для заданих областей).

2. **Частина 2: Аналіз енергоспоживання (Household Power Consumption)**
   * Очищення датасету від пропущених значень (символи `?`), типізація колонок.
   * Виконання комплексних фільтрацій за критеріями (активна потужність, напруга, суб-метрики).
   * Випадкова вибірка даних (Data Sampling).
   * Нормалізація та стандартизація числових ознак.
   * Застосування техніки One-Hot Encoding для категоріальних даних.
   * Розрахунок коефіцієнтів кореляції Пірсона та Спірмена між параметрами.

## Структура папок та файлів проєкту

* `Part1_NOAA_Analysis.ipynb` — Jupyter-блокнот із першою частиною завдання.
* `Part2_Household_Power.ipynb` — Jupyter-блокнот із другою частиною завдання.
* `requirements.txt` — список усіх залежностей (бібліотек) для запуску лабораторної роботи.

> ⚠️ **Важлива примітка щодо датасетів:** Папка з сирими даними `datasets/` (зокрема файл `household_power_consumption.txt`, який важить понад 120 МБ) додана до файлу `.gitignore` і не завантажується на GitHub відповідно до лімітів розміру файлів на платформі та правил гарного тону розробки.

## Інструкція з розгортання та запуску проекту

Для ізоляції залежностей та коректного відтворення результатів аналізу, запуск лабораторної роботи необхідно виконувати всередині ізольованого віртуального середовища Python (`venv`).

### 1. Створення віртуального оточення
Перейдіть у кореневу директорію репозиторію та створіть віртуальне середовище (назвемо його `.venv`):

```bash
python3 -m venv .venv```

###2. Активація віртуального оточення
Перед встановленням бібліотек обов'язково активуйте створене середовище:

Для Linux / MacOS (Ubuntu, Kali Linux тощо):

```bash
source .venv/bin/activate
```
Для Windows (PowerShell):

```PowerShell
.venv\Scripts\Activate.ps1```
(Після активації на початку вашого рядка в терміналі з'явиться префікс (.venv)).

###3. Встановлення необхідних залежностей
Оновіть системний менеджер пакетів pip та встановіть бібліотеки, що зафіксовані у файлі requirements.txt:

```bash
pip install --upgrade pip
pip install -r requirements.txt
```
###4. Запуск Jupyter Notebook
Для перегляду та виконання коду лабораторної роботи запустить локальний сервер Jupyter:

```bash
jupyter notebook```

Після цього у браузері відкриється інтерфейс, де ви зможете по черзі запустити блокноти Part1_NOAA_Analysis.ipynb та Part2_Household_Power.ipynb.
