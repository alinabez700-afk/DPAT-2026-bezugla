# Лабораторна робота №2: Аналіз даних та профілювання в Pandas

## Опис роботи
Реалізовано комплексний аналіз двох великих датасетів за допомогою бібліотеки `pandas`. Проведено часове профілювання кожної процедури за допомогою модуля `timeit`.

### Структура папки:
* `Part1_NOAA_Analysis.ipynb` — модуль аналізу VHI індексів (очищення, пошук екстремумів, виявлення років екстремальних посух).
* `Part2_Household_Power.ipynb` — модуль аналізу енергоспоживання (Data Cleaning, комплексні фільтрації, випадкові вибірки, нормування/стандартизація, One-Hot Encoding та розрахунок кореляцій Пірсона/Спірмена).O
