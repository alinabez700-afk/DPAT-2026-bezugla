# Лабораторна робота №4: Інтерактивний застосунок для генерації та фільтрації гармонічних сигналів

## Опис проекту
У рамках цієї роботи реалізовано інтерактивну програму на базі бібліотеки `matplotlib` та інструментів `scipy.signal`. Застосунок дозволяє користувачеві в реальному часі моделювати фізичні сигнали виду $y(t) = A \cdot \sin(\omega t + \phi)$, накладати на них випадкові шуми за розподілом Гаусса та досліджувати ефективність цифрової фільтрації.

## Функціональні можливості
* **Параметризація гармоніки:** Плавне регулювання амплітуди, частоти та початкової фази сигналу через віджети `Slider`.
* **Моделювання шуму:** Налаштування математичного сподівання ($\mu$) та коваріації/дисперсії ($\sigma^2$) шуму.
* **Оптимізоване керування пам'яттю:** Програма розділяє обчислення. Зміна параметрів гармоніки не призводить до генерації нового шуму (він залишається статичним на графіку), а зміна параметрів шуму не збиває виставлені налаштування сигналу.
* **Перемикання режимів:** Чекбокс `Show Noise` дозволяє миттєво вмикати або вимикати зашумлений сигнал, залишаючи лише «чисту» лінію.
* **Цифрова фільтрація:** Накладений шум згладжується за допомогою низькочастотного фільтра Баттерворта 4-го порядку. Параметр `Cutoff Freq` регулює частоту зрізу фільтра.
* **Скидання стану:** Кнопка `Reset` миттєво повертає всі компоненти системи до дефолтних значень.

## Використаний стек технологій
* `numpy` — генерація часових векторів та масивів випадкових чисел (шуму).
* `matplotlib.pyplot` — побудова графічного вікна та відтворення сигналів.
* `matplotlib.widgets` — створення GUI-компонентів (`Slider`, `Button`, `CheckButtons`).
* `scipy.signal` (`iirfilter`, `lfilter`) — розрахунок та застосування цифрового фільтра Баттерворта.

## Інструкція з розгортання та запуску проекту

Для ізоляції залежностей та коректної роботи GUI-віджетів і фільтрів SciPy, запуск лабораторної роботи необхідно виконувати всередині ізольованого віртуального середовища Python (`venv`).

### 1. Створення віртуального оточення
Перейдіть у кореневу директорію репозиторію та створіть віртуальне середовище:

```bash
python3 -m venv .venv

```

### 2. Активація віртуального оточення

Перед встановленням бібліотек обов'язково активуйте створене середовище:

* **Для Linux / MacOS (Ubuntu, Kali Linux тощо):**
```bash
source .venv/bin/activate

```


* **Для Windows (PowerShell):**
```powershell
.venv\Scripts\Activate.ps1

```
*(Після активації на початку вашого рядка в терміналі з'явиться префікс `(.venv)`).*

### 3. Встановлення необхідних залежностей

Оновіть системний менеджер пакетів `pip` та встановіть бібліотеки, що зафіксовані у файлі `requirements.txt` четвертої лаби (включаючи `scipy`):

```bash
pip install --upgrade pip
pip install jupyter
pip install -r lab_04/requirements.txt

```

### 4. Запуск Jupyter Notebook

Для запуску інтерактивного застосунку виконайте команду:

```bash
jupyter notebook

```
