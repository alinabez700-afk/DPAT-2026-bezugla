# Лабораторна робота №5: Наука про дані: обмін результатами та початковий аналіз

## Опис проекту
У рамках цієї лабораторної роботи реалізовано веб-додаток на базі фреймворку `Streamlit`. Застосунок виконує роль інтерактивної веб-панелі (Dashboard) для обміну результатами досліджень та аналізу екологічних індексів (VCI, TCI, VHI) на основі історичних даних серверів NOAA з Лабораторної роботи №2.

## Функціональні можливості
* **Панель фільтрації (Ліва колонка):**
  * Вибір типу часового ряду (VCI, TCI, VHI) за допомогою выпадаючого списку.
  * Вибір адміністративної області для глибокого аналізу.
  * Повзунки-слайдери діапазонів (Range Sliders) для гнучкого налаштування інтервалів тижнів та років.
  * Кнопка миттєвого скидання всіх виставлених фільтрів до початкового стану.
* **Аналітична зона (Права колонка з вкладками):**
  * Вкладка `📋 Таблиця даних`: Відображення динамічно відфільтрованої таблиці з метрикою загальної кількості знайдених рядків та опціями сортування за зростанням або спаданням значень.
  * Вкладка `📈 Графік часового ряду`: Хронологічний лінійний графік обраного індексу для конкретної області з оптимізованим кроком міток часу.
  * Вкладка `📊 Порівняння областей`: Стовпчикова діаграма, що порівнює середні значення обраного індексу по всіх регіонах, де аналізована область акцентовано підсвічується контрастним кольором.

## Інструкція з розгортання та запуску проекту

Для ізоляції веб-застосунку та його залежностей, запуск проекту необхідно виконувати всередині віртуального середовища Python (`venv`).

### 1. Створення та активація віртуального оточення
Перейдіть у кореневу директорію репозиторію та виконайте:
```bash
python3 -m venv .venv
source .venv/bin/activate
```
###2. Встановлення пакетів
Оновіть pip та встановіть файли залежностей, які знаходяться всередині папки п'ятої лабораторної:

```bash
pip install --upgrade pip
pip install -r lab_05/requirements.txt
```
###3. Запуск веб-додатка Streamlit
Локальний сервер додатка запускається командою:

```bash
streamlit run lab_05/app.py
```
Після цього у вашому браузері автоматично відкриється вкладка за адресою http://localhost:8501 з інтерактивним інтерфейсом.
