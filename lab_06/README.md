# Лабораторна робота №6: Інтерактивна обробка відеосигналу за допомогою OpenCV та C++

## Опис проекту
У рамках цієї роботи реалізовано модульний C++ застосунок для захоплення, аналізу та інтерактивної обробки відеопотоку з веб-камери в реальному часі за допомогою бібліотеки `OpenCV`. Проект спроектований за модульною архітектурою (кожен логічний компонент винесено в окремий клас) та збирається за допомогою кросплатформної системи `CMake`.

## Функціональні можливості
* **Захоплення відеопотоку:** Клас `CameraProvider` ініціалізує та безпечно керує з'єднанням із пристроєм камери.
* **Обробка кадрів (FrameProcessor):** Динамічне накладання ефектів без затримок у потоці та розрахунок FPS.
* **Панель керування (Trackbar):** Інтерактивний GUI-повзунок для плавного регулювання яскравості зображення.
* **Режими обробки (KeyProcessor):** Перемикання ефектів за допомогою клавіатури:
  * `0` — **Normal:** Оригінальне зображення з камери.
  * `1` — **Inversion:** Попіксельна інверсія кольорів (ефект негативу) за допомогою `bitwise_not`.
  * `2` — **Gaussian Blur:** Цифрове згладжування/розмиття фільтром Гаусса для зниження високочастотних шумів.
  * `3` — **Canny Filter:** Виділення меж та контурів об'єктів за допомогою алгоритму Кенні.
  * `4` — **Glitch Effect:** Ефект хроматичної аберації (безпечний зсув червоного каналу ліворуч, а синього — праворуч).
* **Вихід:** Кнопка `ESC` для коректного звільнення системних ресурсів і закриття вікон.

## Вимоги до системи та заліза
* **ОС:** Linux (тестовано на Kali Linux / Ubuntu 22.04+).
* **Залізо:** Наявність підключеної веб-камери (вбудованої або USB), інтегроване або дискретне графічне ядро для рендерингу GUI.
* **Компілятор:** С++ версії 17 (`g++` або `clang`).
* **Утиліти білду:** `CMake` версії 3.10+, `make`.

## Інструкція з розгортання та запуску

Для перевірки роботи програми на чистій системі розроблено зручні автоматизовані баш-скрипти. Запуск здійснюється у три кроки:

### 1. Попереднє встановлення залежностей
Встановлює бібліотеку OpenCV, систему збирання CMake та необхідні компілятори:
```bash
./preinstall.sh
```
###2. Компіляція та білд проекту
Створює директорію build/, конфігурує CMake та компілює бінарний файл:

```bash
./build.sh
```
###3. Запуск застосунку
Запускає скомпільовану програму:

```bash
./run.sh
```
Примітка: Якщо скрипти видають помилку доступу, виконайте команду chmod +x preinstall.sh build.sh run.sh.
