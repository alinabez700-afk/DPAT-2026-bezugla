# Лабораторна робота №7: Багатопотоковий комп'ютерний зір на C++ із використанням OpenCV DNN

## Опис проекту
У рамках цієї лабораторної роботи розширено функціонал модульного C++ застосунку для обробки відеопотоку. Реалізовано асинхронний режим детекції облич на базі глибокої нейромережі **ResNet-10 (SSD)** через модуль `cv::dnn`. 

Для вирішення проблеми блокування головного графічного інтерфейсу (UI) важкими математичними обчисленнями нейромережі, процес інференсу винесено в окремий фоновий робочий потік (**Worker Thread**) за допомогою `std::thread`, а синхронізація та захист спільних даних реалізовані через примітиви `std::mutex` та `std::unique_lock`.

## Функціональні можливості
* **Асинхронний інференс (Рівень 2):** Відеопотік залишається ідеально плавним (30–60 FPS), оскільки головний потік не чекає на завершення роботи нейромережі.
* **Детекція облич:** Розпізнавання облич у реальному часі з фільтрацією точності (Confidence > 50%) та малюванням обмежувальних рамок (Bounding Boxes).
* **Модульна архітектура проекту:**
  * `CameraProvider` — Захоплення та передача сирих кадрів з камери.
  * `KeyProcessor` — Обробка клавіш. Новий режим детекції вмикається клавішею `5` (Face Detection).
  * `FaceDetector` — Окремий клас-сервіс, який керує фоновим потоком (`std::thread`), ініціалізує Caffe-модель, приймає копії кадрів під м'ютексом і асинхронно оновлює координати знайдених облич.
  * `FrameProcessor` — Накладання класичних ефектів з ЛР6 та рендеринг рамок облич, що передаються з потоку детектора.
  * `Display` / `main` — Головний потік, що забезпечує взаємодію компонентів та виведення вікна.

## Вимоги до системи
* **ОС:** Linux (тестовано на Kali Linux).
* **Залізо:** Веб-камера (вбудована або USB-зовнішня).
* **Залежності:** `OpenCV` (з модулем dnn), `CMake` 3.10+, компілятор з підтримкою `C++17` (`g++`).

## Інструкція з розгортання та запуску

Проект підтримує стандарт швидкого розгортання на чистій системі за допомогою трьох автоматизованих скриптів:

### 1. Попереднє встановлення та завантаження нейромережі
Скрипт інсталює системні залежності та автоматично створює папку `models/`, завантажуючи туди конфігурацію моделі (`.prototxt`) та бінарні ваги (`.caffemodel`):
```bash
./preinstall.sh
```
### 2. Компіляція проекту
Конфігурує збірку через CMake та збирає виконуваний файл:

```bash
./build.sh
```

### 3. Запуск застосунку
Запускає готову програму детекції:

```bash
./run.sh
```
Керування програмою (Гарячі клавіші)
0 — Оригінальний відеопотік (Normal).

1 — Інверсія кольорів (Inversion).

2 — Розмиття Гаусса (Gaussian Blur).

3 — Контури Кенні (Canny Filter).

4 — Глітч-ефект (Glitch Effect).

5 — Детекція облич (Асинхронний Face Detection за допомогою фонового потоку).

Повзунок Brightness — Плавне регулювання яскравості.

ESC — Безпечний вихід із програми, зупинка фонових потоків та реліз камери.
